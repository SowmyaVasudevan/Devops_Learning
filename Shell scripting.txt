we need to tell our Linux kernel that with these executables, we will execute the shell script

widely used one is bash 
in Linux we have a think called linking so previous day even if we are using "sh", it will redirect to "bash" 
but now by default it is going for "dash" 
so don't complicate the script, use what executables you're using in the script
interview questions : diff b/w bash, sh?
previously both of them were same, because /sh will direct to /bash using the linking concept, but now it is not same because some of the OS are decided to use dash as default, so our script might not execute bash scripting in the system where dash is default
